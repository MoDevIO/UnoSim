# I/O Registry Pin Infos Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add Programmed Pins (n), All Pins, and Pin Infos inside the I/O Registry without changing source navigation or runtime findings.

**Architecture:** Keep the existing usage rows and file-aware location rendering. A pure board reference model derives signal rows from the hardware profiles, enriches them with pinned-core bus and interrupt metadata, and supplies nonprogrammable reference contacts separately. A focused Pin Infos component renders the reference; ParserOutput owns the subtab and existing detail state.

**Tech Stack:** TypeScript, React, Radix Tabs, existing semantic Tailwind tokens, UnifiedScrollArea, Vitest, Playwright.

**Spec:** `docs/superpowers/specs/2026-10-27-pin-infos-design.md`

## Global Constraints

- All GUI copy is English; nine columns and one header row.
- Reuse TabBar/Tabs, toolbar controls, typography and semantic color tokens. No raw color literals.
- Preserve both usage views, static/runtime origins, conflicts, counts, file/line targets, and detail state.
- Pin Infos works without a sketch or running simulation and follows board changes.
- No separate Sketch/Alias, Port, ADC-channel, Chip leg, or Notes column.
- RESET restrictions, Nano analog-only pins, USI master roles, and Mega PCINT core restrictions remain explicit.
- PWM is 8 bit (0–255); Analog In is 10 bit (0–1023).
- Do not touch the user's Serial Monitor modifications. Work on `feat/io-registry-pin-infos` based on `feature/browser-emulation`.

## Review Focus

- Board changes while Pin Infos is open must replace old board rows and reset an incompatible query.
- Returning from Pin Infos must retain file-aware source navigation and the detail toggle's state.
- Empty static registries and runtime-only records must preserve counts, origins and access to all pins.
- Nano A6/A7 and ATtiny RESET must never appear as unrestricted digital pins.
- Scrolling at narrow widths or increased font scale must retain the single header and Pin column without page overflow.
